# 📡 Network Packet Analyzer

A modern web-based **Network Packet Analyzer** built with **Python, Flask, and Scapy**. The application captures live network traffic, analyzes packets, and displays real-time statistics through an interactive dashboard.

---

## 🚀 Features

* Live Packet Capture
* TCP, UDP, ICMP, and DNS Detection
* Real-Time Packet Statistics
* Live Packet Table
* REST API Architecture
* Responsive Web Dashboard
* Modular Project Structure

## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Move into the project folder:

```bash
cd Network-Packet-Analyzer
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment.

**Windows**

```bash
venv\Scripts\activate
```

**Linux**

```bash
source venv/bin/activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser:

```text
http://127.0.0.1:5000
```
